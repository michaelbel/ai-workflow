# Git Rules

- Commit only related changes together; stage selectively and use clear, focused messages.
- Commit dependency updates one per commit as `Bump <dependency> from <old version> to <new version>` — even if multiple deps are in the same file, apply each change separately and commit individually.
- When asked to commit, commit all current changes in one or more focused commits. Do not leave files modified or restore prior context over the user's current changes.
