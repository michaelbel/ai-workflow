# Static screen

Используй этот режим, когда экран не загружает и не наблюдает данные.

- Не добавляй искусственные `LoadData`, `isLoading`, use case или `init` только ради шаблона.
- Model содержит только состояние, которое реально меняется: выбранную вкладку, раскрытую секцию,
  локальный toggle и подобное.
- Intent нужен только для реальных действий. Навигационное действие отправляет Event через
  `send(...)`, а публичный Screen обрабатывает его через `ObserveAsEvents`.
- Даже если экран полностью детерминирован входными аргументами, создай обязательные `ViewModel`,
  `Model` и `Intent` по MVI-контракту проекта, но не добавляй в них фиктивную загрузку или состояние.
- Preview должен показывать содержательные визуальные варианты, а не loading/content, которого у
  экрана нет.
