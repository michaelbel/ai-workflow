# Output Contract

## Основные артефакты

Гайд считается опубликованным только тогда, когда существуют и связаны:

1. публичный GitHub-репозиторий с рабочим Android-проектом;
2. связанная страница в Notion: существующая страница, обновлённая на месте, или новая страница в `POSTS` по умолчанию.

Если пользователь явно просит только черновик, допускается остановиться до публикации. Во всех остальных случаях локальные файлы без URL не считаются завершённым результатом.

## Рабочие артефакты

Создаваемый репозиторий содержит:

```text
.guidekit/
├── manifest.yaml
├── research.md
├── implementation-plan.md
├── SOURCES.md
└── validation-report.md
```

- `manifest.yaml` фиксирует выбранный scope;
- `research.md` содержит технические выводы до реализации;
- `implementation-plan.md` связывает требования с файлами и samples;
- `SOURCES.md` хранит первичные источники и происхождение кода;
- `validation-report.md` хранит реальные результаты проверок.

## Готовность результата

Гайд готов, если:

- все сценарии из манифеста реализованы;
- обязательные Gradle-задачи прошли;
- страница написана по фактической реализации;
- код и ссылки в Notion проверены;
- версии совпадают;
- существенные ограничения API указаны рядом с соответствующими компонентами или сценариями;
- AndroidX-заимствования атрибутированы.

## Финальный ответ агента

Используй структуру:

```markdown
# Гайд создан

GitHub: <url>
Notion: <url>
Тип проекта: <catalog | scenario | single>

## Реализовано

- ...

## Проверки

- `:app:assembleDebug` — успешно;
- `:app:lintDebug` — успешно;
- ...

## Версии

- Kotlin: ...
- Compose: ...
- Topic API: ...

## Источники

- ...

## Ограничения

- ...
```

Не пиши «успешно», если проверка не запускалась. Используй «не запускалась» и объясни причину.
